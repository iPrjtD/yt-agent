# Music beds

Put royalty-free tracks here, one mood per folder (mp3/wav/m4a/ogg). The agent rotates them quietly under
the narration (about -20 dB) and fades them out at the end.

| Folder | Used for | Look for |
|---|---|---|
| `upbeat/` | facts, trending | bright, light electronic / pop, 100-125 BPM |
| `funny/` | funny | quirky, comedic, pizzicato, ukulele |
| `inspiring/` | motivation | cinematic piano, strings, slow build |
| `ambient/` | stories | soft cinematic, suspense, documentary |

Where to get them (free, no copyright claims): YouTube Studio -> Audio Library -> filter
"Attribution not required". Download 3-5 tracks per folder. Audio files are not committed to git.
